# 시이카와 · 수학과학 원리 탐험

과학고등학교·과학영재학교를 준비하는 학생을 위한 한국어 원리장 PWA입니다. 수학 16회차, 물리 14회차, 화학 13회차, 생명과학 14회차, 지구과학 15회차로 구성됩니다. 총 72회차에서 432개 원리, 객관식 예제 1,728개, 면접 미션 144개를 연습할 수 있습니다.

사랑하는 우리 딸을 위해 만든 앱입니다. 개인적 목적으로 테스트하기 위해 만든 앱이기 때문에 상업적 활용 불가능합니다. 저작권 문제도 있습니다.

## 실행

이 폴더의 상위 소스 루트 `C:/dev/20261023-science-voca`에서 실행합니다. Node22.12이상(현재 검증24)과 npm이 필요합니다.

```powershell
npm ci
npm run dev
```

개발 서버의 기본 포트는 4175입니다. 포트가 사용 중이면 Vite가 실제 주소를 출력합니다. 배포용 빌드를 확인하려면 다음 명령을 실행합니다.

```powershell
npm run build
npm run serve
```

PC에서 `http://localhost:4176/`을 열어 빌드 결과를 확인합니다. 서비스 워커는 HTTPS 또는 같은 기기의 `localhost`에서 작동합니다. iPhone에서 설치와 오프라인 동작을 확인할 때는 아래의 HTTPS 배포 주소를 사용하세요.

## 학습 방식

원리장을 선택하고 탐험을 시작합니다. 기억 채우기와 회차의 빈자리까지 선택한 원리장 안에서 출제하고, 원리장마다 진도를 따로 이어갑니다. 한 회차에 새 원리6개를 중심으로 기본20문제(기억4,탐험12,설명2,미션2)를 풉니다. 처음 틀린 탐험 문제만 마지막에 다른 예문으로 한 번 더 연습합니다. 설명은 소리 내어 말한 뒤 실제로 말한 채점 요소를 직접 체크하며 녹음하지 않습니다. 30초 타이머는 선택 사항입니다.

복습함은 친구의 연구실,10문제 원리 테스트,원리장 바로가기 순서입니다. 원리 테스트는 배운 전체 원리에서 객관식5개와 첫 글자 힌트 개념어 입력5개를 뽑습니다. 입력 채점은 띄어쓰기와 전각/반각을 정규화합니다. 원리장 열람만으로 XP·진도는 오르지 않습니다. 각 원리의 ‘이 원리 깊이 연습’에서는 설명+응용 2문제를 추가 XP 없이 반복하며 모든 원리의 능동 연습 기록을 쌓을 수 있습니다.

SRS는 원리 ID 기준1·1·3·7·14·30일 간격입니다. 객관식 인지,힌트를 본 입력,설명 자기점검을 구분합니다. 숙련은 서로 다른 날3회 성공,능동 연습2일,미션 성공과7일 뒤 능동 성공을 모두 요구합니다. 설명은 자기 평가이므로 실제 구술 능력이나 합격 가능성을 인증하지 않습니다.

## 콘텐츠와 근거

- `content/decks/*.deck.json`: 원리장 원본. 파일 추가만으로 자동 목록화됩니다.
- `content/research-sources.json`에는 공식 공개 경로, 실제로 열람한 범위와 접근 제한을 정리했습니다.
- 각 원리·미션 source: 개념을 참고한 파일·쪽·공개 자료. 기출 문장을 복제하지 않고 새로운 문항을 작성했습니다.

2026년 11월 원리장 확장에서는 `references/`의 기출 PDF 80개와 2,026쪽을 목록화했습니다. 파일과 페이지의 중복을 대조해 서로 다른 렌더링 페이지 622쪽을 분류했고, 그중 텍스트가 부족한 이미지 157쪽은 한국어 OCR로 보완했습니다. 선정한 문항의 도표·수식·그림은 이미지와 대조했습니다. 각 원리의 출처에서 참고한 PDF 쪽과 문항을 확인할 수 있습니다.

파일별 분류, 문항 유형과 학습 경로는 로컬 `docs/REFERENCE_EXAM_COVERAGE.md`에 있습니다. `references/`와 `history/`의 원본, OCR 텍스트, 분석 보고서는 로컬에 보관합니다. OCR은 문항을 찾는 데 사용했고 원문을 앱에 싣지 않았습니다. `draft`는 문항별 독립 교육 검수가 남았음을 뜻합니다.

## 기록과 보상

IndexedDB `siikawa-local-v1`에 학습·정답·SRS·보상·구매·설정을 저장합니다. 영어 앱 DB를 읽지 않습니다. XP는 객관식/개념 입력 첫정답10,미션20,설명 완료15(통과 여부 무관),회차완료30. 오답재도전은 추가XP없음. 원리테스트는 완료시에만 해당 회차 최대XP의30%를 첫정답비율만큼 지급합니다. 중복 제출과 중복 구매는 트랜잭션으로 방지합니다.

사용자가 `avatar/`에 제공한 인형 사진을 참고해 만든 투명 배경의 2D 시이카와·시이카로·시이쿠마 아바타와42종 꾸미기(무료3종 포함)를 제공합니다. 배경3200,옷1600,액세서리700XP. 유료결제·랜덤뽑기·광고는 없습니다. 미구매 배경은 구매 후에만 그림이 나타납니다. 배포한 아바타도 서비스워커의 오프라인 캐시에 포함합니다.

설정에서 `시이카와-YYYY-MM-DD.json`을 백업하고 가져올 수 있습니다. 새 백업의 앱 식별자는 `시이카와`입니다. 기존 `시이싸이`와 `Siikawa` 스키마 1 백업에도 동일한 검사를 적용합니다. IndexedDB `siikawa-local-v1`에 학습·XP·구매·장착 기록을 저장합니다. 스키마·문항 참조·답변·XP·영수증·숙련 상태를 검증한 후 이 기기의 기록을 백업 내용으로 한 번에 복원합니다.

## iPhone에 설치하고 오프라인으로 학습하기

1. 인터넷에 연결한 iPhone의 Safari에서 배포 주소를 엽니다. [시이카와 열기](https://profsong.github.io/sikawa/)
2. **공유 → 홈 화면에 추가**를 선택합니다. **웹 앱으로 열기**가 보이면 켜고 **추가**를 누릅니다. 공유 메뉴에서 항목을 찾을 수 없다면 메뉴 하단의 **동작 편집**을 확인합니다. [Apple의 홈 화면 추가 안내](https://support.apple.com/ko-kr/guide/iphone/iph42ab2f3a7/ios)
3. 홈 화면의 **시이카와** 아이콘으로 앱을 엽니다. 최초 실행은 온라인에서 진행하고, 화면 아래에 **오프라인 학습 준비 완료**가 표시될 때까지 기다립니다. 이때 학습 화면과 원리장, 이미지가 기기에 저장됩니다. [서비스 워커의 오프라인 준비 안내](https://vite-pwa-org.netlify.app/guide/prompt-for-update)
4. 비행기 모드에서 Wi-Fi도 끈 뒤 홈 화면 아이콘으로 다시 열어 원리장을 보고 한 문제를 풀어 보세요. 오프라인에서 푼 기록도 그 앱에 저장됩니다.

Safari 탭에서 이미 학습했다면 탭의 **설정 → 백업 파일 저장**으로 JSON을 보관하고, 홈 화면 앱을 연 뒤 **설정 → 백업 가져오기**에서 파일을 선택하세요. Safari 탭과 홈 화면 웹 앱은 학습 저장소를 따로 쓰므로 점수가 자동으로 옮겨지지 않습니다. 기기나 배포 도메인을 바꿀 때도 같은 방식으로 옮깁니다. 백업 가져오기는 선택한 파일의 기록으로 현재 앱의 기록을 교체합니다. [WebKit의 홈 화면 웹 앱 저장소 설명](https://webkit.org/blog/14787/webkit-features-in-safari-17-2/)

## iPhone에서 새 버전 받기

1. 새 빌드가 배포되면 인터넷에 연결하고 평소 사용하던 홈 화면 아이콘으로 **오늘의 탐험**을 엽니다.
2. 새 버전이 준비되면 **오늘의 탐험**에서 풀이와 저장을 진행하지 않는 동안 자동으로 적용됩니다. 다른 화면에서 **새 원리 탐험이 도착했어요**가 보이면 풀이를 마치고 **업데이트 적용**을 누를 수도 있습니다. [서비스 워커 업데이트 방식](https://vite-pwa-org.netlify.app/guide/prompt-for-update)
3. 다시 열린 앱에서 기존 진도와 XP를 확인합니다. 새 버전의 파일이 기기에 저장되면 오프라인에서도 이용할 수 있습니다.

일반 업데이트는 기존 설치에서 진행합니다. 앱 삭제나 웹사이트 데이터 정리를 하기 전에는 설정에서 JSON 백업을 저장하세요. 이 절차의 실제 iPhone 검증은 별도로 필요합니다. [WebKit 저장소 정책](https://webkit.org/blog/14403/updates-to-storage-policy/)

## 기존 점수를 보존하며 문항 업데이트하기

- 새 문항은 새 ID로 추가하고, 새 원리는 출시된 6개 묶음 뒤에 새 회차로 붙입니다. 이미 출시한 원리장의 ID와 원리의 ID·순서를 유지하면 이전 진도를 같은 회차로 찾을 수 있습니다. 이미 완주할 수 있었던 짧은 마지막 회차의 빈자리를 나중에 채우면 그 회차가 다시 열리지 않으므로, 그런 원리장은 새 원리장으로 이어가는 것이 안전합니다.
- 기존 문항의 보기와 보기 순서, 정답, 개념어 정답 목록·힌트, 설명 채점 기준, 미션의 지문·근거 문장은 채점 기록의 일부입니다. 심화 연습 지문으로 쓰이는 원리 요약도 포함됩니다. 이 항목들을 변경하거나 이전 문항을 제거하면 현재 원리장과 대조하는 이전 백업 복원이 거부될 수 있습니다. 정답 오류나 문항 퇴역을 처리할 때는 이전 채점 자료를 보존하는 마이그레이션을 먼저 마련하고 이전 백업을 새 빌드에서 복원해 검증하세요.
- 기존 회차는 원리 순서로 나눈 6개 단위의 번호에 연결됩니다. 중간 원리를 삭제하거나 `retired`로 바꾸면 뒤 원리가 다른 회차로 밀릴 수 있습니다. 출시된 회차를 재구성해야 할 경우 기존 진도와 새 회차를 연결하는 작업을 먼저 검증하세요.

## 검사와 배포

```powershell
npm run validate:decks
npm run typecheck
npm run lint
npm test
npm run build
npm run test:e2e
```

GitHub Pages의 게시 원본은 **Settings → Pages → Build and deployment → Source → GitHub Actions**로 설정합니다. `main`에 변경을 올리면 `Deploy GitHub Pages` 워크플로가 검사하고 빌드합니다. 수동으로 다시 배포할 때는 **Actions → Deploy GitHub Pages → Run workflow**에서 `main`을 선택합니다. [GitHub Pages 배포 원본 설정](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

워크플로가 Pages의 `/sikawa/` 경로를 읽어 빌드하며, 웹에는 `dist/`만 배포합니다. 수정할 문항은 `content/decks/`에 있습니다. 이미 원격과 연결한 `main` 작업 복사본에서 수학 원리장을 수정한 경우 다음처럼 올릴 수 있습니다. [GitHub Pages 사용자 지정 워크플로 안내](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)

```powershell
npm run validate:decks
git add content/decks/math-reasoning.deck.json
git commit -m "Update math deck"
git push origin main
```

Actions에서 배포 성공을 확인한 뒤 설치한 iPhone 앱을 온라인으로 엽니다. GitHub Pages는 문항과 앱 파일을 제공하며 학습 기록은 각 기기에서 보관합니다. [배포 주소](https://profsong.github.io/sikawa/)

기존 영어 자료는 자동 삭제 검토 제한으로 `artifacts/legacy-source/`에 되돌릴 수 있게 분리했습니다. 이 경로는 TypeScript·lint·테스트·빌드와 웹배포에서 제외됩니다. 실제 앱과 dist에는 영어 학습 자료가 포함되지 않습니다. history·motivation·분석 텍스트·원본 PDF/HWP도 dist에 포함하지 않습니다.

소스 열람·웹앱 사용·링크 공유의 조건은 LICENSE를 참조하세요. 타사 의존성에는 각 의존성의 라이선스가 계속 적용됩니다.

앱 표시 이름은 시이카와입니다. 앱 상단에는 시이카와 캐릭터 아이콘과 이름을 함께 표시합니다. 사용자 제공 인형 사진을 참고한 2D 친구 아바타 3종은 각각 투명한 배경을 사용합니다.

스마트폰 홈 화면에 설치하는 웹앱의 기본 아이콘은 시이카와 캐릭터입니다. iPhone용 Apple touch 180px, 일반 설치용 192/512px, 안드로이드의 모양별 마스킹용 512px 아이콘을 제공합니다. 앱 안의 친구 선택과 관계없이 설치 아이콘은 시이카와로 고정합니다. 아이콘 원본은 `assets/branding/siikawa-install-master.png`이며 `npm run generate:icons`로 배포용 크기를 재생성합니다.
